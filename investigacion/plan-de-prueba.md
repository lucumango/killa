## 4. La IA del chat: mini evaluación con Gemini

El chat del celular (Flor, Amaru y el grupo) usa una IA. Para el paper se va a usar la API de Gemini. El prompt ya tiene las reglas de chanka que salieron de las consultas con Abner (`js/datos/ia.js`).

### Qué se puede afirmar según lo que se haga

- **Solo con el prompt:** se describe como decisión de diseño ("las reglas del prompt salen de la consulta con un intérprete de chanka"). No se puede afirmar que el chat responde en chanka correcto. Va en limitaciones.
- **Con la mini evaluación:** se puede reportar cuánto mejora el chanka con las reglas.

### La mini evaluación

1. Escribir 30 mensajes de jugador: quechua bien escrito, quechua roto, castellano y cosas sin sentido.
2. Gemini contesta cada uno dos veces: con un prompt básico y con el prompt con las reglas de Abner. En total son 60 respuestas.
3. Abner las revisa sin saber cuál es cuál, en orden mezclado, y marca en cada una: ¿es chanka?, ¿se entiende?, ¿hay errores? Le toma una hora o una hora y media, unos S/ 80–100.
4. Resultado: "con las reglas, X de 30 respuestas fueron juzgadas como chanka correcto por un intérprete, contra Y de 30 sin ellas". Si las reglas no mejoran nada, también es un hallazgo.

Para hacerla, hay que pasar `servidor-ia/` de Claude a Gemini y armar un script que genere las 60 respuestas en una hoja para Abner.

### Trabajo futuro: un revisor automático

Las diferencias entre collao y chanka siguen reglas fijas, así que se pueden detectar y corregir con un programa antes de mostrar la respuesta:

| Collao (Cusco) | Chanka (Ayacucho) | Ejemplo |
|---|---|---|
| ph, th, kh, qh, chh | p, t, k, q, ch | mikhuy → mikuy |
| p', t', k', q', ch' | p, t, k, q, ch | p'unchay → punchaw |
| -sha- (estar haciendo) | -chka- | kashan → kachkan |
| allill- | allinll- | allillanchu → allinllachu |
| e, o en palabras quechuas | solo a, i, u | diospagarasunki → diuspaqarasunki |

El revisor corregiría lo mecánico. Si queda algo sin arreglar, le pediría al modelo que reescriba, y si vuelve a fallar usaría la respuesta local del juego. Todo quedaría en un registro.

Hallazgo para el paper: las listas de internet de las que partió el guion mezclaban quechua de Cusco con el de Ayacucho (*allillanchu*, *p'unchay*, *qhilli*, *-sha-*). Eso muestra el sesgo hacia el quechua de Cusco que tienen los recursos en línea, el mismo que pueden tener los modelos.
